# Demo and portfolio

## Live URL

https://kind-meadow-03cf73103.7.azurestaticapps.net/

## Correct description

Live portfolio/demo environment for an Insurance AI Platform and Auto Claims Operations Dashboard. It demonstrates product flow and UI integration using demo data; it is not described as a production customer environment.

## Main screens and concepts

- operational claims overview;
- claim lifecycle and queue;
- claim workspace;
- documents and photos;
- AI processing state;
- AI recommendation and confidence;
- risk assessment;
- human approval;
- audit events;
- token/cost/latency visibility.

## Technical explanation

- React/TypeScript live dashboard;
- Redux Toolkit/Redux-Saga patterns for async workflow;
- stable REST API contracts;
- integration with Go, ASP.NET Core, and Python/FastAPI services;
- role-aware navigation and backend-enforced authorization;
- loading, empty, failure, retry, and long-running operation states;
- AI recommendations remain traceable and reviewable before human action.

## Angular positioning

Angular/TypeScript represents enterprise workflow modules and previous/full-stack experience: RxJS services, routing, reactive forms, guards/interceptors, validation, reusable tables, and administrative screens. Do not claim that every page in the live React demo is also implemented in Angular.
